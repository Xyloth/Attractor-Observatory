# FAIR Data Stewardship Statement

Status: public-surface policy, TASK-DX-002-FIX.

This repository is a curated public research surface. It is FAIR-aligned for public artifacts and explicitly private-bounded for generated traces and private runtime code.

## Findable

- Campaign reports live under `reports/campaign_*/full_report.json`.
- Methodology documents live under `papers/methods/`.
- Doctrine lives under `docs/DOCTRINE.md` and `docs/doctrine_registry.json`.
- Machine-readable package metadata lives in `ro-crate-metadata.json`.

## Accessible

- Public artifacts are accessible in this branch.
- Private runtime code and per-seed trace dumps are not shipped; reports mark those references with `evidence_private: true` and `trace_path_status: private_unshipped`.
- Collaborator access to private runtime artifacts is controlled by the PI.

## Interoperable

- JSON reports use explicit `schema` fields where available.
- Doctrine and lineage records carry SHA-256 hashes.
- PROV-O-compatible JSON-LD is emitted per campaign under `reports/campaign_*/prov_o.jsonld`.

## Reusable

- Public policy, docs, and code are MIT-licensed unless an artifact states otherwise.
- Source-bound records carry license class and provenance where generated by the Factory.
- `metadata_only` source material is not redistributed raw.

## Non-claim

This statement does not claim external FAIR certification. It documents the public-surface stewardship policy and the private-evidence boundary.
