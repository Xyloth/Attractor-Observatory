The Attractor Observatory


A computational research instrument that generates possible worlds, mines them for recurring stable structures, compares those structures against Earth’s biological history, and then asks whether current mathematics compresses those structures cleanly — or whether the gaps point toward new formal objects.

The north-star claim:

Life is one observed trajectory through a larger space of stable energy-information attractors. Build the machine that explores that space.

The brutal version:

We are not trying to explain life after the fact.
We are trying to build a universe-sampler that discovers which forms are hard to avoid.

0. The top ambition

The highest bar is not:

“We found patterns in biology.”

That is weak.

The highest bar is:

We built a substrate-neutral attractor discovery system, showed that real biological history occupies a non-random subset of the attractors it discovers, and identified recurring structures that existing mathematical frameworks describe only in fragments.

That gives us three outputs:

A science output — a new way to model life’s history.
A software output — a simulation and motif-mining engine.
A mathematical output — a map of where current formal tools fail to compactly describe recurring living-system structures.

That third one is the dangerous one.

That is the one that could become “missing math.”

2. The real object of study

The object is not an organism.

The object is not a species.

The object is not even “life.”

The object is:

A recurring, self-stabilizing process-form

A process-form is a pattern that persists through time because it captures flow, maintains structure, stores state, or reproduces part of its organization.

Examples:

cycle
closure
boundary
gradient tracking
branching transport
modularity
repair
replication
division
symmetry breaking
swarm coordination
distributed sensing
memory
prediction
hierarchical control
externalized information

The most primitive serious seed remains:

Autocatalytic closure under energy flow

RAF theory is the formal anchor here: a Reflexively Autocatalytic and Food-generated set is a reaction network that can form and persist from an available food source, and RAFs have been applied to origin-of-life, metabolism, ecology, and even cultural-evolution models.

But the ambitious move is to generalize closure.

Not just:

chemical reactions catalyze each other

but:

a system produces, repairs, predicts, or reinforces the conditions of its own continuation

That lets us track closure across:

chemistry
protocells
metabolism
development
immune systems
brains
insect colonies
ecosystems
cultures
markets
software systems
AI systems

The big question becomes:

What forms of closure exist, which are stable, and which recur across substrates?

You said not to skimp here. So don’t.

The simulation side should be built as a pluralistic generative engine: many world types, one common trace format, one motif-mining system.

7. The node-strength metric

The project needs one central number — not because one number is the truth, but because it forces discipline.

Call it:

Attractor Strength

A node is strong if it is not just pretty, not just common, and not just hand-labeled.

A node is strong when it scores high on:

recurrence
persistence
robustness
basin width
cross-substrate transfer
implementation diversity
compression value
predictive value
formal irreducibility

More formally:

AttractorStrength(M) =
  R(M) × P(M) × B(M) × X(M) × D(M) × C(M) × V(M)

Where:

R = recurrence across independent runs
P = persistence over time
B = basin width under varied initial conditions
X = cross-world transfer
D = diversity of implementations
C = compression gain over raw description
V = predictive value on held-out systems

Then add:

F = formal coverage
G = formal gap = importance / formal coverage

So a motif that is common, stable, transferable, predictive, and poorly compressed by current math becomes a missing-math candidate.

That is the bar.

Not vibes.

Not “this feels profound.”

A measured compression failure.

8. The math-inversion engine

This is the part that can become genuinely original.

Normal science asks:

Which mathematical tool explains this biological thing?

This project asks:

Which biological/system motifs repeatedly exceed our current mathematical compression?

Build a library of mathematical lenses:

graph theory
network science
chemical reaction network theory
dynamical systems
stochastic processes
information theory
thermodynamics
control theory
topological data analysis
category theory
process algebra
Petri nets
game theory
statistical mechanics
computational mechanics

For every discovered motif, evaluate:

Can this formalism represent it?
Can it predict it?
Can it distinguish it from nearby motifs?
Can it preserve the relevant invariants across substrates?
Can it compose motifs hierarchically?
Can it express boundary, memory, repair, and reproduction together?

Then produce a Formal Coverage Matrix.

Example:

Motif: self-maintained boundary

Graph theory: partial
Topology: partial
Control theory: partial
Information theory: partial
Thermodynamics: partial
Markov blankets: partial
Chemical reaction network theory: weak unless chemistry-specific
Unified representation: missing

Formal gap: high

That is not yet new math.

But it is a research map pointing toward where new math may be needed.

A real missing-math clue looks like:

1. Motif recurs across many simulated worlds.
2. Motif appears in real biology.
3. Motif is predictive on held-out cases.
4. Motif transfers across substrates.
5. Current math describes pieces, but no compact formalism captures the whole invariant.

That is the ladder from observation to new abstraction.

9. The biological grounding layer

Once the artificial worlds are running, ground them against Earth.

Use Earth as the observed trace, not the whole possibility space.

The core datasets:

Open Tree of Life
Paleobiology Database
GBIF
NCBI Datasets
GTDB
KEGG / metabolic pathway data where licensing allows
morphology datasets
behavioral/ecological trait datasets

Open Tree of Life synthesizes published phylogenetic trees and taxonomic data into a broad digital tree of life. The Paleobiology Database API provides programmatic access to fossil taxonomic, spatial, and temporal data. GBIF provides occurrence access and batch downloads for global biodiversity records. NCBI Datasets provides web, CLI, and API access for downloading genome, gene, sequence, annotation, and metadata packages. GTDB is especially important for microbial life because it offers standardized genome-based bacterial and archaeal taxonomy; its site currently lists Release 11-RS232 from April 15, 2026, with 901,341 genomes.

But do not merely ingest taxa.

Represent organisms and clades as uncertain motif observations:

  clade
  time_range
  motif
  substrate
  evidence_type
  confidence
  absence_status
  source
  notes

The absence status is critical:

present

unknown
probably absent
structurally absent
not applicable

Never let this happen:

not observed = false

That error would poison the entire atlas.

The biological comparison asks:

Do artificial attractors correspond to biological convergences?
Do clades cluster by motif independent of taxonomy?
Do extinct forms occupy attractor regions now empty?
Do major transitions correspond to new closure levels?
Do convergent traits sit in high-strength basins?
Do some predicted basins lack known biological examples?

Convergent evolution is a natural benchmark because it already concerns independently acquired similar traits across lineages; recent work continues to treat convergence as widespread across the tree of life and examines its genetic foundations.

11. The discovery system

The simulation engine should not just run random sweeps.

It should actively search.

Use several search modes:

random parameter sweeps
Latin hypercube sampling
evolutionary search
novelty search
quality-diversity search
Bayesian optimization
active learning
curriculum generation
adversarial perturbation

The reason: if the answer is hiding in noise, bigger sample size helps — but only if the sample is diverse.

A trillion near-identical runs is trash.

A smaller set that systematically spans weird corners of possibility-space is gold.

The search objective is not one fitness score.

Use many objectives:

maximize persistence
maximize novelty
maximize closure
maximize boundary stability
maximize reproduction fidelity
maximize information retention
maximize recovery after perturbation
maximize cross-run recurrence
maximize motif diversity
maximize compressibility

The system should constantly ask:

What have we not seen yet?
Which parameter regions are underexplored?
Which motifs are rare but stable?
Which motifs appear only after perturbation?
Which motifs require multiple scales?
Which motifs emerge only with lineage history?

This is how you find the weird stuff.

13. The validation gauntlet

The project needs a ruthless filter.

A motif only graduates from “interesting” to “candidate attractor” if it survives:

Test 1 — Recurrence

Does it appear across independent seeds?

Test 2 — Basin width

How much can initial conditions change before the motif disappears?

Test 3 — Perturbation recovery

Damage it. Does it return?

Test 4 — Implementation diversity

Does the same motif appear in different material forms?

Test 5 — Cross-world transfer

Does it appear in more than one simulator family?

Test 6 — Biological grounding

Does Earth life show a corresponding structure?

Test 7 — Null comparison

Does it survive against randomized histories, shuffled networks, random graphs, and permuted phylogenies?

Test 8 — Prediction

Can it predict held-out simulations or biological cases?

Test 9 — Compression

Does naming the motif reduce description length or improve model performance?

Test 10 — Formal coverage

Can existing mathematics capture it compactly?

Only after all that does something become a real candidate node.

This protects the project from becoming a pattern-matching machine.

14. The “missing math” version of success

Here is the best-case chain.

simulate many worlds
→ discover recurring process-form M
→ show M recurs across substrates
→ show M appears in real biology
→ show M predicts held-out examples
→ try existing math frameworks
→ each captures only fragments
→ define invariant that current frameworks miss
→ build new formal object around that invariant
→ show new object compresses and predicts better

That is the dream.

Possible first missing-math candidates:

1. Self-maintained boundary

A boundary that is not just a surface, not just a graph cut, not just a Markov blanket, and not just a membrane.

It is a process that:

separates
regulates exchange
is produced internally
is repaired under damage
stabilizes identity through time

Existing math has pieces. The unified object is weak.

2. Closure rank

A hierarchy of closure types:

C0: passive persistence
C1: cyclic recurrence
C2: catalytic closure
C3: bounded closure
C4: reproductive closure
C5: developmental closure
C6: cognitive closure
C7: cultural/technological closure

This could become a real formal ladder.

3. Cross-substrate attractor equivalence

When are a chemical network, an ant colony, and a software system “the same” process-form?

Not metaphorically.

Formally.

That requires a mapping that preserves functional invariants while ignoring material substrate.

4. Adaptive identity through replacement

Living systems persist even as matter turns over.

A flame does this weakly. A cell does it strongly. A culture does it abstractly. A company does it institutionally. An AI model lineage may do it computationally.

What is the invariant?

That is not cleanly solved by ordinary object-based math.

5. Externalized memory

DNA, pheromone trails, writing, roads, source code, trained weights, institutional procedure.

Same broad process:

state leaves the organism
persists in environment
alters future behavior
enables continuity across individuals

This is a monster motif.

Existing math touches it, but does not unify it.

Build the trace/motif architecture before chasing biology.

3. Build motif detectors.

The observatory has to discover before it explains.
