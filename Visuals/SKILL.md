If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

The load-bearing rule of this design system is the **five-status semantics**: Verified · Active · Exploratory/Candidate · Missing · Falsified. Every visual element must encode one of these — never confuse Missing with Verified, never confuse Candidate with Claim-bearing. Empty rooms beat stocked rooms (D22).
